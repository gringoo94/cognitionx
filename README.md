## 🧰 Открытые инструменты самопомощи

Все инструменты бесплатны, работают в браузере, без регистрации и без отправки данных на сервер.

| Инструмент | Описание |
|---|---|
| [ABC-анализ](https://cognitionx.cloud/tools/abc-analysis) | Классическая схема КПТ: событие → мысль → эмоция → поведение |
| [Дневник мыслей](https://cognitionx.cloud/tools/thought-diary) | Работа с автоматическими мыслями и когнитивными искажениями |
| [Планировщик дня](https://cognitionx.cloud/tools/day-planner) | Поведенческая активация при депрессии и апатии |
| [Колесо эмоций](https://cognitionx.cloud/tools/emotion-wheel) | Развитие эмоциональной грануляции |
| [Матрица решений](https://cognitionx.cloud/tools/decision-matrix) | Структурированный выбор при прокрастинации |
| [Дыхательные практики](https://cognitionx.cloud/tools/breathing) | Регуляция тревоги и панических состояний |
