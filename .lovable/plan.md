## Цель

После завершения любого теста (PHQ-9, GAD-7 и т.д.) пользователь сможет скачать подробный PDF-отчёт, чтобы переслать его психологу.

## Что попадёт в PDF

1. **Шапка**: название и код теста (например, «PHQ-9 · Опросник депрессии»), дата и время прохождения, пометка «Скрининг, не диагноз».
2. **Итог**: общий балл (X из Y, %), уровень (`levelLabel`), интерпретация и рекомендация из `scoring()`.
3. **Подшкалы**: таблица «название → балл / макс» для тестов, где есть `subscales` (FMPS, RRS и др.).
4. **Все вопросы с ответами**: нумерованный список «вопрос → выбранный вариант (балл)».
5. **Поле для заметок**: текстовое поле на странице результата → если пользователь что-то написал, текст попадает в раздел «Что хочу обсудить».
6. **Футер**: ссылка на сайт `cognitionx.cloud` и контакт для записи.

## Техническая реализация

- Библиотека: **jsPDF** + **jspdf-autotable** (легче, чем react-pdf; работает на клиенте без серверной генерации).
- Новый модуль `src/lib/testReportPdf.ts` с функцией `generateTestReportPdf(config, answers, userNote)`:
  - Поддержка кириллицы: подключить шрифт **PT Sans / Roboto** (TTF → base64) через `doc.addFileToVFS` + `doc.addFont`, иначе кириллица в jsPDF ломается. Шрифт положить в `src/assets/fonts/`.
  - Расчёт подшкал — переиспользовать ту же логику, что в `TestResult` (вынести `sumByItems` в `src/data/tests/scoring.ts` или дублировать).
  - Layout: title → метаданные → score card → subscales table → answers table → user note → disclaimer + footer на каждой странице.
- Имя файла: `{code}-report-{YYYY-MM-DD}.pdf`, например `PHQ9-report-2026-06-13.pdf`.

## Без backend

Генерация полностью на клиенте — никакой записи в БД, никаких личных данных на сервере. Это сохраняет обещание «Анонимно», которое уже стоит в шапке теста.
