## Технические детали

- **Стек:** React 18 + Vite + Tailwind CSS + TypeScript
- **SEO:** react-helmet-async (динамический) + vite-plugin-seo (статический pre-render для ботов)
- **Аналитика:** Google Analytics (встроен)
- **Форма записи:** отправка уведомлений в Telegram
- **Язык:** русский (весь контент)
- **Целевая аудитория:** русскоязычные пользователи (Россия, СНГ, экспаты в Европе/США)
