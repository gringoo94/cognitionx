## План работ (приоритизирован по ROI)

### P0 — Брендовый CTR (1 релиз)

1. Переписать `<title>` и `<meta description>` страницы `/cognitionx` так, чтобы они отвечали брендовому интенту:
   - title: `CognitionX — психолог Дмитрий Яцко | КПТ онлайн`
   - description: краткое УТП + призыв «Запишитесь на консультацию».
2. То же для главной `/`: title должен содержать слово «CognitionX» рядом с именем, чтобы брендовые запросы кликались на главную, а не на `/cognitionx`.
3. Убедиться, что Organization JSON-LD (уже есть в `index.html`) содержит корректный `name`, `alternateName: ["CognitionX","Cognition X"]`, `url`, `logo` — для триггера sitelinks.
4. Проверить, что `/cognitionx` не каннибализирует главную: либо сделать 301 → `/`, либо чётко разделить интент (страница «о бренде»).

### P1 — Разгон страниц поз. 8–15 (контент + перелинковка)

Для каждой из 6 страниц-кандидатов:
1. Добавить H1/intro, точно содержащие целевой запрос (например, «постоянная тревога без причины» дословно в H1 блог-поста).
2. Расширить контент до 1200–1800 слов: симптомы, причины, что делать, когда к специалисту.
3. Добавить FAQ-блок (3–5 Q&A) с FAQPage JSON-LD — даёт rich snippet и +CTR.
4. Внутренняя перелинковка: с главной, со связанных блог-постов, из футера — на каждую из этих 6 страниц минимум 2 входящие ссылки.
5. Обновить `lastReviewed` (как уже сделано для проблемных страниц) — Google любит свежесть.

### P2 — США / `/psiholog-usa`

1. Перенести `/psiholog-usa` в приоритетные: расширить контент (часовые пояса, оплата из США, лицензирование/отказ от ответственности, отзывы клиентов из США).
2. Добавить дочерние страницы `/psiholog-nyu-jork`, `/psiholog-los-andzheles`, `/psiholog-chikago` (как уже сделано для городов Европы) и связать их с `/psiholog-usa` хабом.
3. Добавить hreflang `en` версию (минимум landing-страницу) — США кликают на английские заголовки чаще.
4. Прописать LocalBusiness/Service schema с `areaServed: "United States"`.

### P3 — Закрепить выигрыши

1. `/in-person-therapy` (CTR 21%) — расширить, превратить в полноценную лендинг-страницу с формой записи, добавить в главное меню.
2. `/cbtworkbook` (поз. 6.67) — добавить FAQ schema, отзывы, превью-скриншоты тетради → поднять в топ-3.
3. По запросу «кпт тетрадь» (CTR 100%) и связанным («рабочая тетрадь кпт», «дневник кпт») — собрать кластер: посадочная + 2–3 блог-поста с перелинковкой.

### P4 — Технические проверки после релиза

1. Опубликовать сайт (Publish → Update) — без этого правки canonical/hreflang/title не дойдут до Google.
2. Через 24–48 ч проверить через Rich Results Test ключевые URL: `/`, `/cognitionx`, `/cbtworkbook`, `/blog/postoyannaya-trevoga-bez-prichiny`.
3. В GSC отправить sitemap.xml на повторную индексацию + URL Inspection для P0/P1 страниц → «Request Indexing».
4. Через 2 недели снять повторный отчёт GSC и сравнить позиции/CTR по тем же 6 страницам.
