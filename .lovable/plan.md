

## Извлечение следующих страниц книги

### Проблема
Парсер документов обрабатывает только первые 50 страниц. Книга содержит 384 страницы, глава про препятствия — предположительно во второй половине.

### Решение
1. Скопировать PDF в песочницу
2. С помощью `pypdf` разрезать книгу на части по 50 страниц (стр. 51-100, 101-150 и т.д.)
3. Парсить нужные части, найти главу про препятствия
4. Извлечь текст для использования в статьях

### Что потребуется
- `code--exec` для запуска Python-скрипта разрезки PDF
- `document--parse_document` для парсинга полученных частей

### Файлы проекта
Никакие файлы проекта не изменяются — это вспомогательная задача по извлечению контента.
