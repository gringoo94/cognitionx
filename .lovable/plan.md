

## Улучшение структуры меню: группировка + мега-дропдаун

### Текущие проблемы
- 11 специализаций в одном плоском списке — сложно ориентироваться
- Нет логической группировки (проблемы, методы, формат терапии перемешаны)
- Дропдаун узкий (w-56), одна колонка — длинный скролл
- Нет описаний — пользователь не понимает разницу

### Что сделаем

**1. Группировка специализаций на 3 категории:**

```text
┌─────────────────────────────────────────────────────┐
│  Специализации                                       │
├──────────────┬──────────────┬────────────────────────┤
│  Проблемы    │  Методы      │  Формат               │
│  ─────────   │  ─────────   │  ─────────             │
│  Депрессия   │  КПТ-терапия │  Онлайн-терапия        │
│  Тревога     │  Схема-      │                        │
│  Панические  │  терапия     │                        │
│  атаки       │              │                        │
│  Выгорание   │              │                        │
│  Созависим.  │              │                        │
│  Самооценка  │              │                        │
│  Стресс      │              │                        │
│  Зависимость │              │                        │
└──────────────┴──────────────┴────────────────────────┘
```

**2. Десктоп — мега-меню (3 колонки):**
- Ширина ~480px, три колонки с заголовками категорий
- Заголовки категорий — мелкий серый текст (uppercase, text-xs)
- Иконки остаются у каждого пункта
- Плавная анимация (как сейчас)

**3. Мобильное меню — вложенные секции:**
- Внутри раскрытых «Специализаций» три подгруппы с заголовками
- Визуальное разделение через border-l + отступы (как сейчас, но с группами)

### Файлы для изменения

| Файл | Действие |
|------|----------|
| `src/components/Navbar.tsx` | Реструктуризация specLinks на 3 группы, мега-меню десктоп (3 колонки), группированный мобильный дропдаун |

### Технические детали

- Структура данных: массив `specGroups` с полями `title` и `links[]`
- Десктоп: `grid grid-cols-3` внутри дропдауна, ширина увеличена до `w-[480px]`
- Мобиль: каждая группа с заголовком `text-xs uppercase text-muted-foreground` и отступом
- Анимации framer-motion остаются без изменений
