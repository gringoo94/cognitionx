## Техническая реализация

**Файл:** `src/data/blogPosts.ts` — добавить 14 новых записей в массив `blogPosts`, используя существующий формат `parseContent(JSON)`.

**Общая статья** будет использовать `componentId: "emotion-wheel"` для встраивания интерактивного колеса (по аналогии с `behavioral-activation-diary`). Потребуется добавить обработку этого `componentId` в `BlogPost.tsx`.

**Контент** — каждая статья будет сгенерирована с помощью AI (Lovable AI Gateway), чтобы обеспечить психологически грамотный, авторский текст на основе работ Брене Браун ("Atlas of the Heart").

**Теги:** `["Эмоции", "Самопомощь"]` для всех статей.

**SEO:** Каждая статья автоматически получит Schema.org Article разметку через существующую инфраструктуру `BlogPost.tsx` + `SEOHead`.
