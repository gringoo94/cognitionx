

# Уведомления о заявках в Telegram-бот

## Что будет сделано
При каждой новой заявке (с главной страницы и со страницы контактов) бот в Telegram отправляет вам сообщение с данными клиента: имя, email, мессенджер, текст запроса.

## Шаги

### 1. Подключить Telegram-коннектор
Подключим Telegram-бот через встроенный коннектор Lovable. Вам нужно будет указать токен бота (получается у @BotFather в Telegram).

### 2. Создать Edge Function `notify-telegram`
Функция принимает данные заявки и отправляет сообщение в указанный чат через Telegram Bot API (connector gateway). Формат сообщения:

```
📋 Новая заявка
Имя: Иван
Email: ivan@mail.ru
Мессенджер: @ivan_tg
Запрос: Хочу записаться на консультацию
```

Для этого нужен ваш **chat_id** в Telegram (бот отправляет сообщения именно вам). Его можно узнать, написав боту `/start` и проверив через API.

### 3. Обновить формы отправки
В `BookingForm.tsx` и `ContactPage.tsx` после успешной вставки в базу — вызвать Edge Function `notify-telegram`, чтобы уведомление ушло сразу.

### 4. Сохранить chat_id как секрет
Chat ID будет храниться как секрет проекта (`TELEGRAM_CHAT_ID`), чтобы не хардкодить в коде.

## Что потребуется от вас
1. Создать бота через @BotFather (если ещё нет) и получить токен
2. Подключить бота через диалог коннектора
3. Написать боту `/start`, чтобы я мог определить ваш chat_id
