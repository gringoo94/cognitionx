# Убрать других специалистов со страницы записи

На странице записи остаётся только Дмитрий и его платная консультация. Данные коллег сохраняются, чтобы их можно было быстро вернуть.

## Что меняется на странице /free-consultation
- Заголовок: «Запись на консультацию к Дмитрию Яцко», без упоминания бесплатных 20 минут.
- Короткий текст: до ноября новые клиенты не принимаются, но разовая платная консультация доступна с записью примерно за 2 недели.
- Блок с уведомлением остаётся, но без фразы «выберите одного из коллег».
- Убираются: кнопка «Выбрать специалиста», карточки Жени, Юли, Насти и Анны, блок «Не знаете, кого выбрать?».
- Форма записи сразу открыта для Дмитрия (платная консультация). Текст подтверждения остаётся прежним.
- Заголовок и описание страницы для поисковиков переписываются под платную запись к Дмитрию, без бесплатной консультации и команды.

## Страницы специалистов
- Адреса вида /specialists/... для коллег ведут обратно на страницу записи, чтобы по старым ссылкам не открывались их профили.

## Технические детали
- Добавить в `src/data/specialists.ts` флаг `teamBookingEnabled = false`. В `FreeConsultationPage.tsx` при выключенном флаге выбор сразу ставится на `dmitrii`, а сетка карточек и блок подбора не показываются.
- В `SpecialistPage.tsx` при выключенном флаге для любого id, кроме `dmitrii`, сделать `<Navigate to="/free-consultation" replace />`.
- Поправить SEOHead и JSON-LD сервиса на этой странице.
