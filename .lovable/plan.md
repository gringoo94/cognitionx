# Новые цены: 40 € разовая, 140 € пакет из 4

## Что меняется

- Было: первая консультация 25 €, регулярная сессия 30 €, пакет 4 × 25 € = 100 €.
- Станет: **разовая консультация — 40 € (50 мин)**, **пакет из 4 сессий — 140 € (35 € за сессию)**.
- Отдельный тариф «первая консультация» убирается: первая встреча оплачивается как разовая, 40 €.
- Бесплатная 20-минутная встреча-знакомство остаётся везде без изменений.
- В пакете указываем экономию 20 € (вместо 160 € при разовых).

## Где правим (найдено по всему проекту)

Блок цен (карточки тарифов — из трёх делаем две):
- `src/components/Pricing.tsx` (главная)
- `src/pages/LandingPageEuropa.tsx`, `LandingPageAsia.tsx`, `LandingPageIT.tsx`, `LandingPageKishinev.tsx`
- `src/pages/CityLandingPage.tsx` (шаблон всех городских лендингов)

Текстовые упоминания цен:
- `src/components/Hero.tsx` — строка под кнопками («Первая консультация — 25 €»)
- `src/components/HomeFAQ.tsx` — ответ про стоимость
- `src/pages/AboutPage.tsx`
- `src/pages/LandingPageEuropa.tsx` (FAQ + бейджи), `LandingPageAsia.tsx` (FAQ), `LandingPageKishinev.tsx` (FAQ про оплату)
- `src/data/cityPages.ts` — 10 упоминаний «50 минут, 25 €» в FAQ городов
- `src/data/problemExtras.ts` — объект цен (`firstSession`, `regularSession`, `pack`) и FAQ-ответ; структура упрощается до разовой + пакета
- `public/llms.txt` — два упоминания «первая консультация — 25 €» (правится в шаблоне генератора, чтобы не затиралось)

## Технические детали

- В `problemExtras.ts` тип блока цен меняется с трёх позиций на две (`session: 40`, `pack: { total: 140, perSession: 35, count: 4 }`); все компоненты, читающие эти поля, обновляются вместе.
- Карточки лендингов сейчас содержат hardcoded массив из 4 позиций (0 €, 25 €, 30 €, пакет). Оставляем 3: бесплатное знакомство, разовая 40 €, пакет 140 €.
- В `llms.txt` правим исходник генератора (`scripts/gen-llms-txt.mjs` / статическая часть), затем перегенерируем каталоги: `bun run scripts/gen-llms-txt.mjs`, манифест блога и MCP-каталог.
- JSON-LD `Offer` с `price: "0"` для бесплатных инструментов и бесплатной встречи не трогаем.
- В конце — прогон `npm run seo:check` для проверки пререндера и метаданных.
