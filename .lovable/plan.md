
# План проверки и роста конверсии + SEO/GEO

Работаем в два этапа: сначала аудит (диагностика), потом план реализации по результатам. Аудит — это сбор данных; правки кода пойдут отдельной итерацией после твоего согласия.

---

## Этап 1. Аудит (диагностика, без правок кода)

### 1.1 Аналитика и поведение
- `page_views` за 30 дней: топ-страницы, bounce, скролл-глубина, время на странице.
- `contact_submissions`: конверсия по источнику страницы (`/`, `/psiholog-europa`, `/psiholog-kishinev`, `/psiholog-asia`, `/psiholog-italia`, `/ocd`, тесты, блог).
- Воронка: визит → клик CTA (Telegram/форма) → submit.
- Точки отвала: где >70% уходят без действия.

### 1.2 Посадочные (конверсия)
Прохожу каждую посадку (`Index`, `LandingPageEuropa`, `LandingPageKishinev`, `LandingPageAsia`, `LandingPageIT`, `/ocd`, проблемные страницы, city pages) по чек-листу:
- Оффер виден в первом экране (≤ 600px desktop / ≤ 740px mobile)?
- Один первичный CTA на экран, понятный (Telegram / форма / бесплатная консультация)?
- Social proof рядом с CTA (отзывы, опыт, образование)?
- Sticky-CTA на мобиле?
- Скорость загрузки LCP/CLS (Lighthouse).
- Форма: длина, обязательные поля, валидация, подтверждение.

### 1.3 Тесты как воронка
- Все 20+ тестов: есть ли CTA-блок в `TestResult` по тяжести и кластеру.
- Pre-fill сообщения в Telegram с результатом.
- Связки «тест → проблемная страница → запись».

### 1.4 SEO (technical + on-page)
- `seo_chat--list_findings`: текущие failing/ignored.
- Метатеги: title ≤ 60, description ≤ 160, canonical, og:* per route.
- H1 единственный, иерархия H2/H3.
- JSON-LD: Article (блог), FAQPage, BreadcrumbList, MedicalBusiness/Physician (главная), Quiz/WebApplication (тесты).
- Внутренняя перелинковка: блог ↔ тесты ↔ проблемные страницы ↔ посадки.
- `sitemap.xml`, `robots.txt`, `llms.txt`.
- Дубли контента, тонкие страницы.

### 1.5 SEO performance (Semrush)
- `domain_analysis` cognitionx.cloud — текущие позиции, трафик.
- `top_pages` — что уже работает.
- `seo_trend` — динамика.
- `competitive_analysis` против b17.ru, psy.help, alter.ru — гэпы.
- Keyword research по 5–7 кластерам: «психолог онлайн», «КПТ», «психолог кишинёв», «психолог [город ЕС]», «тест на депрессию», «ОКР терапия», «схема-терапия».

### 1.6 GEO (Generative Engine Optimization — для ChatGPT/Perplexity/Gemini)
- `llms.txt` / `llms-full.txt` покрытие: все ли важные страницы там.
- Структурированные ответы: FAQ-блоки с прямыми ответами в первых 2 предложениях.
- Цитируемость: статьи с тезисами, цифрами, источниками — то, что LLM любят цитировать.
- Author E-E-A-T: страница «Об авторе», био, квалификация, sameAs.
- Schema.org Person + medicalSpecialty + alumniOf (уже частично есть).

### 1.7 Контент-аудит блога
- Какие статьи приносят трафик (Semrush page-level).
- Какие висят без позиций — переписать или удалить.
- Кластеризация: pillar + supporting articles.

### Deliverable аудита
Документ с тремя списками:
1. **Quick wins** (≤ 1 час, большой эффект).
2. **Средние правки** (1–4 часа).
3. **Стратегические** (новые страницы, контентные кластеры).

## Этап 2. План реализации (после согласия)

После того как покажу результаты аудита, разобьём работу на спринты. Ориентировочные направления (уточним по фактам):

### Спринт A — Конверсия (1–2 дня)
- Унификация CTA на всех посадках: sticky Telegram + основная форма + «бесплатная 20-мин встреча» как chip.
- Сокращение формы записи до минимума (имя + контакт + 1 поле «что беспокоит»).
- Усиление social proof возле каждого CTA (отзыв + N клиентов + образование).
- A/B заголовков на двух главных посадках (`/` и `/psiholog-europa`).
- Pre-fill Telegram-сообщения везде, где его ещё нет.
- Exit-intent / scroll-CTA на длинных страницах блога.

### Спринт B — SEO on-page (2–3 дня)
- Починка всех failing findings из SEO-сканера.
- Расширение посадок по городам ЕС (там, где трафик есть, но контент тонкий).
- Внутренняя перелинковка: автоматические блоки «связанные тесты / статьи / проблемы» на тестах и в блоге.
- Schema enrichments: Quiz schema на тестах, MedicalCondition на проблемных страницах, HowTo на инструментах.
- Обновление `sitemap.xml` lastmod + приоритеты по фактическому трафику.

### Спринт C — GEO / LLM-видимость (1–2 дня)
- `llms-full.txt`: полный корпус с разделами, чтобы LLM могли цитировать.
- На каждой ключевой странице — TL;DR-блок (3–5 строк) для прямого извлечения ответа.
- Расширение FAQ-блоков (минимум 6 Q/A на каждой посадке и проблемной странице).
- Страница «Об авторе» с расширенным E-E-A-T (если её ещё нет в текущем виде).
- Author byline + дата обновления в каждой статье блога.

### Спринт D — Контент (постоянно)
- 3–5 pillar-статей по топ-кластерам из Semrush-гэпов.
- Переписать/удалить тонкие статьи.
- Новые проблемные страницы под высокообъёмные запросы (по результатам keyword research).
