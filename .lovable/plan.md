
# Инструмент «Планировщик дня» (поведенческая активация)

Новый инструмент в `/tools/day-planner` в стиле существующих (ThoughtDiary, ABC-анализ, BehavioralActivation). Локальное хранение в браузере, без входа. Основан на статье `planirovanie-dnya-pri-depressii`.

## Структура страницы

Один экран с тремя разделами-табами (или последовательно, прокруткой):

**1. Наблюдение (Шаг 1)** — журнал того, что уже происходит
- Таблица строк: время, действие, энергия 0–10, удовольствие 0–10, результат 0–10
- Кнопка «Добавить запись», удаление строки
- Подсказка: «Заполняйте 1–2 дня, не каждый час»

**2. План на завтра (Шаги 2–5)**
- Оценка доступной энергии слайдером 0–10 → показывает соответствующий «принцип плана» из таблицы статьи
- Три поля-опоры:
  - Необходимое действие + минимальная версия + время/сигнал
  - Удовольствие/облегчение + минимальная версия + время/сигнал
  - Результат/смысл + минимальная версия + время/сигнал
- Поле «С кем связаться, если станет тяжелее»
- Кнопка «Сохранить план на сегодня»

**3. Отметка после действия (Шаг 6)**
- Список сегодняшних запланированных опор
- Для каждой: три ползунка 0–10 (удовольствие, результат, связь со смыслом) + короткое поле «что заметил»
- Чекбокс «Выполнено» / «Использована минимальная версия» / «Не сделано»

**История (последние 14 дней)**
- Список дней с мини-показателями: средняя энергия, кол-во выполненных опор
- Мини-графики (sparkline на SVG, без библиотек) для энергии/удовольствия/результата по дням
- Клик по дню → просмотр деталей, кнопка «Удалить»
- Экспорт JSON и «Печать/PDF» через `window.print()` (как в других инструментах)

## Хранение

- `localStorage` ключ `cx.day-planner.v1`
- Схема: `{ observations: Entry[], days: { [YYYY-MM-DD]: DayPlan } }`
- `DayPlan`: `{ energyForecast, pillars: {type, action, minimal, when, done, pleasure, mastery, meaning, note}[], support }`
- `Entry`: `{ id, date, time, action, energy, pleasure, mastery }`
- Версионирование через ключ, миграция при чтении
