

# Переделка `/psiholog-europa` в посадочную страницу для рекламы

## Проблема

Сейчас страница использует общий шаблон `ProblemPage` — текстовая простыня без визуального акцента. Для рекламной кампании нужна landing page с четкой воронкой: внимание → доверие → действие.

## Что изменим

### 1. Новый компонент `LandingPageEuropa.tsx`

Отдельный компонент (не общий ProblemPage), заточенный под конверсию:

**Hero-секция (above the fold):**
- Крупный заголовок: "Русскоязычный психолог для экспатов в Европе"
- Подзаголовок с болью: "Сложные вещи хочется обсуждать на родном языке"
- Фото терапевта (уже есть `hero-photo.webp`)
- CTA-кнопка "Записаться на первую сессию — 25 €"
- Мини-статистика: 200+ клиентов, 5 лет опыта, онлайн

**Блок "Знакомо?" (pain points):**
- 6 карточек с иконками (одиночество, языковой барьер, идентичность и т.д.)

**Социальное доказательство:**
- 2-3 отзыва из существующего массива testimonials

**"Как я работаю" — 4 шага:**
- Компактные шаги с нумерацией

**Цены — встроенный блок:**
- Первая встреча 25€, сессия 30€, пакет 4×25€
- CTA под каждым

**FAQ — аккордеон:**
- Существующие 5 вопросов

**Финальный CTA:**
- Большой блок с двумя кнопками (Telegram + форма)

### 2. Маршрут

Заменим в `App.tsx` маршрут `/psiholog-europa` с `ProblemPage` на новый `LandingPageEuropa`.

### 3. SEO

Все существующие мета-теги, structured data и schema.org останутся. Добавим `noindex: false` явно.

## Технические детали

- Новый файл: `src/pages/LandingPageEuropa.tsx`
- Редактируем: `src/App.tsx` (маршрут)
- Используем: существующие компоненты (`Button`, `Accordion`, `SEOHead`, `Navbar`, `Footer`), данные из `problemPages.ts` и `Testimonials`
- Стиль: полноширинные секции с `max-w-5xl`, чередование фона, больше визуального пространства
