

## Plan: PDF-документ с рекламными кампаниями для Instagram/Facebook

### Что будет создано

Многостраничный PDF-документ с полной рекламной стратегией для 7 проблем (тревога, депрессия, выгорание, отношения, самооценка, стресс, зависимости). Формат — готовый медиаплан для запуска в Meta Ads.

### Структура документа

1. **Титульная страница** — бренд, название, дата
2. **Обзор стратегии** — общая воронка, KPI, бюджетное распределение
3. **7 кампаний** (по 2 страницы на каждую):
   - Целевая аудитория (демография, интересы, боли, поведение)
   - 3 варианта текстов объявлений (заголовок, основной текст, CTA)
   - Рекомендуемые форматы (feed 1080x1080, stories 1080x1920, reels)
   - Визуальная концепция креативов (описание стиля, цвета, настроение)
   - Рекомендуемый бюджет и стратегия ставок
   - Площадка размещения (Instagram Feed, Stories, Facebook Feed)

### Технические детали

- Генерация через ReportLab (Python) с брендовыми цветами сайта
- AI-генерация текстов объявлений через Lovable AI (gemini-2.5-flash)
- Визуальный QA каждой страницы перед доставкой
- Выходной файл: `/mnt/documents/ad-campaigns.pdf`
