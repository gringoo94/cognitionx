# Полный аудит сайта cognitionx.cloud

Результат — отчёт (документ в «Файлах») с расхождениями и возможностями роста, плюс исправление очевидных ошибок после вашего одобрения списка.

## 1. Согласованность контента и цен
- Поиск всех упоминаний цен, длительности, бесплатной встречи, статуса приёма (до ноября, запись за ~2 недели) по страницам, гео-лендингам, статьям, профилям, файлам для ИИ и данным для Google.
- Уже найдено: на странице «Обо мне» написано «Консультация — 20 минут» вместо 50.
- Проверка, что все кнопки ведут на платную консультацию, а коллеги не появляются на странице записи.

## 2. Техническое SEO
- Быстрая SEO-проверка платформы + чтение текущих замечаний.
- Заголовки, описания, canonical, hreflang, sitemap, robots, редиректы, 410, дубли title/description.
- Проверка готового HTML (prerender) по всем маршрутам, включая новые /specialists.

## 3. Поисковая видимость (данные Google Search Console и Semrush)
- Страницы с показами, но низким CTR (позиции 5–15) — кандидаты на новые заголовки.
- Запросы, по которым сайт почти в топе; пробелы против конкурентов.
- Ссылочный профиль: спамные доноры, новые площадки.

## 4. Скорость и стабильность
- Lighthouse для главной, гео-страницы, статьи: LCP, CLS, вес JS.
- Ошибки в консоли и битые ссылки (обход сайта в браузере).

## 5. Конверсия и аналитика
- Путь «страница → запись»: форма, отправка в Telegram, события Meta Pixel/Метрики.
- Проверка мобильной версии ключевых страниц.

## 6. Безопасность бэкенда
- Проверка безопасности и правил доступа к таблицам заявок.

## Итог
Таблица: проблема / где / влияние / приоритет / исправление. Отдельный блок «Opportunities» (5–10 конкретных шагов). Мелкие ошибки (как «20 минут») исправляю сразу, крупные — по вашему выбору.

## Технические детали
Инструменты: rg-поиск по src/public/seo-routes, seo_chat scan, GSC diagnose, semrush domain/competitive/backlink, Playwright-краулер + Lighthouse, scripts/verify-prerender-seo.mjs, test:geo, security scan. Отчёт: /mnt/documents/site-audit-2026-10.md.
